# Etapa 0 — Cómo aprender a programar

Antes de escribir la primera línea de JavaScript, esta etapa enseña a pensar como programador, a instalar y usar las herramientas del oficio (terminal, VS Code, Node.js, Git y GitHub) y a aprender por cuenta propia: leer documentación y usar IA con criterio. Cierra con un proyecto: publicar tu primer repositorio en GitHub.

## Proyecto de cierre

La lección 07 pide publicar en GitHub un repositorio propio con:

- Un `README.md` en español que describe qué quiere construir el estudiante y por qué.
- Un archivo `.gitignore` con al menos una línea.
- Al menos dos commits en su historia.

Este repositorio es la base sobre la que la etapa 1 (JavaScript) construye los primeros ejercicios de código real.
