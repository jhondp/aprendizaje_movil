# Etapa 1 — JavaScript desde cero

Curso base de JavaScript para quien nunca programó. Al terminar la etapa, el estudiante domina variables, tipos, operadores, condicionales, funciones, arrays, objetos, bucles, métodos de array, scope, closures, manejo de errores, módulos y asincronía (callbacks, promesas, async/await), y construye una app de tareas en consola.

**Proyecto de cierre:** app de tareas en consola (`todo.js`), con las funciones `addTask`, `completeTask`, `listTasks` y `pendingTasks` sobre un arreglo de objetos `{ id, title, done }`.
