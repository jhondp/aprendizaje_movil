## Objetivo

Al terminar esta lección podrás crear un array, acceder a sus elementos por índice, y agregar, quitar o recortar elementos con `push`, `pop` y `slice`.

**Prerrequisitos:** `01-javascript/03-funciones`

## Concepto

Hasta ahora cada variable guarda un solo valor. Un array es una estantería numerada: guarda varios valores, uno al lado del otro, y cada espacio tiene un número de posición llamado **índice**. El primer espacio de la estantería es el índice `0`, no el `1`.

### Crear un array y acceder por índice

Un array se escribe entre corchetes, con los valores separados por comas.

```js
const fruits = ["apple", "banana", "cherry"];

console.log(fruits[0]); // apple, el primer elemento
console.log(fruits[2]); // cherry, el tercer elemento
console.log(fruits.length); // 3, la cantidad de elementos
```

`fruits.length` te dice cuántos elementos hay. Como los índices empiezan en `0`, el último elemento válido siempre está en `fruits.length - 1`. Pedir `fruits[3]` en un array de 3 elementos no lanza un error: devuelve `undefined`, porque esa posición no existe.

### Agregar y quitar elementos

`push` agrega un elemento al final del array y devuelve la nueva longitud. `pop` quita el último elemento y lo devuelve.

```js
const numbers = [1, 2, 3];

numbers.push(4);
console.log(numbers); // [1, 2, 3, 4]

numbers.pop();
console.log(numbers); // [1, 2, 3]
```

Ambos métodos modifican el array original: no crean uno nuevo. Esto es importante porque otros métodos que verás en la lección de métodos de array, como `map` y `filter`, sí devuelven un array nuevo sin tocar el original.

### Recortar con slice

`slice(inicio, fin)` devuelve un array nuevo con una copia de los elementos entre las posiciones `inicio` (incluida) y `fin` (excluida), sin modificar el array original.

```js
const letters = ["a", "b", "c", "d"];
const firstTwo = letters.slice(0, 2);

console.log(firstTwo); // ["a", "b"]
console.log(letters); // ["a", "b", "c", "d"], sin cambios
```

Piensa en `slice` como fotocopiar un tramo de la estantería: te llevas la fotocopia, la estantería original queda intacta.

Puedes revisar la referencia completa de arrays en MDN, con todos sus métodos: https://developer.mozilla.org/es/docs/Web/JavaScript/Reference/Global_Objects/Array.

<Callout kind="tip">
  Un array puede guardar cualquier tipo de valor, incluso objetos. En la lección de objetos vas a combinar ambos: un array de objetos es la forma más común de representar una lista de datos, como tareas o usuarios.
</Callout>

## Errores comunes

**Pensar que el primer elemento está en el índice 1.** `fruits[1]` es el segundo elemento, no el primero; el primero es `fruits[0]`. Se detecta comparando el valor obtenido contra el elemento esperado en esa posición.

**Acceder a un índice que no existe y esperar un error.** `fruits[10]` en un array de 3 elementos no lanza ningún error: devuelve `undefined` silenciosamente. Se detecta revisando si el valor obtenido es `undefined` cuando debería haber un dato real; conviene comparar contra `fruits.length` antes de acceder.

**Esperar que slice modifique el array original.** A diferencia de `push` y `pop`, `slice` no cambia el array sobre el que se llama: siempre devuelve uno nuevo. Se detecta porque, después de `const copy = list.slice(0, 2)`, `list` sigue teniendo la misma longitud que antes.
