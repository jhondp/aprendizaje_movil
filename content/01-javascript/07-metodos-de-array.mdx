## Objetivo

Al terminar esta lección podrás transformar un array con `map`, filtrarlo con `filter`, buscar un elemento con `find` y acumular un resultado con `reduce`.

**Prerrequisitos:** `01-javascript/06-bucles`

## Concepto

En la lección anterior recorriste arrays con `for` y `while`, escribiendo tú mismo cada paso: dónde empezar, cuándo parar, qué acumular. Los métodos de array son como contratar a un especialista para cada tarea repetitiva: le entregas el array y una función pequeña que describe qué hacer con cada elemento, y el especialista se encarga del recorrido completo. Tú describes el "qué", el método se encarga del "cómo".

Los cuatro métodos de esta lección nunca modifican el array original: siempre devuelven algo nuevo.

### map: transformar cada elemento

`map` recorre un array y devuelve un array nuevo, del mismo tamaño, con el resultado de aplicar una función a cada elemento.

```js
const numbers = [1, 2, 3, 4];

const doubled = numbers.map((n) => n * 2);
console.log(doubled); // [2, 4, 6, 8]
```

`(n) => n * 2` es la función que `map` aplica a cada elemento. El array `doubled` tiene los mismos 4 elementos que `numbers`, pero transformados.

### filter: quedarse con algunos elementos

`filter` recorre un array y devuelve un array nuevo, solo con los elementos para los que la función devuelve `true`. Puede ser más corto que el original, o incluso vacío.

```js
const evens = numbers.filter((n) => n % 2 === 0);
console.log(evens); // [2, 4]
```

### find: buscar un solo elemento

`find` devuelve el primer elemento para el que la función devuelve `true`, no un array. Si ningún elemento cumple la condición, devuelve `undefined`.

```js
const firstEven = numbers.find((n) => n % 2 === 0);
console.log(firstEven); // 2

const firstNegative = numbers.find((n) => n < 0);
console.log(firstNegative); // undefined
```

### reduce: acumular un solo valor

`reduce` recorre un array y lo reduce a un solo valor, acumulando resultado tras resultado. Recibe dos argumentos: una función con el acumulador y el elemento actual, y el valor inicial del acumulador.

```js
const total = numbers.reduce((sum, n) => sum + n, 0);
console.log(total); // 10
```

En cada vuelta, `sum` es el acumulador (empieza en `0`, el valor inicial) y `n` es el elemento actual. La función devuelve el nuevo valor de `sum` para la siguiente vuelta.

### Los cuatro métodos sobre una lista de tareas

Estos métodos son especialmente útiles sobre arrays de objetos, el patrón que viste en la lección de objetos.

```js
const tasks = [
  { id: 1, title: "Buy milk", done: false },
  { id: 2, title: "Clean house", done: true },
  { id: 3, title: "Write report", done: false },
];

const titles = tasks.map((task) => task.title);
console.log(titles); // ["Buy milk","Clean house","Write report"]

const pending = tasks.filter((task) => !task.done);
console.log(pending); // [{"id":1,"title":"Buy milk","done":false},{"id":3,"title":"Write report","done":false}]

const completedCount = tasks.reduce((count, task) => (task.done ? count + 1 : count), 0);
console.log(completedCount); // 1
```

Puedes revisar la referencia completa de estos métodos en MDN: https://developer.mozilla.org/es/docs/Web/JavaScript/Reference/Global_Objects/Array.

## Errores comunes

**Olvidar el `return` dentro de una función flecha con llaves.** `numbers.map((n) => { n * 2 })` devuelve un array lleno de `undefined`, porque una función flecha con llaves no devuelve nada automáticamente. Se detecta porque el array resultante tiene la longitud correcta pero todos sus valores son `undefined`. Solución: usar `return n * 2;` dentro de las llaves, o quitar las llaves para que la expresión se devuelva sola.

**Olvidar el valor inicial de `reduce`.** `numbers.reduce((sum, n) => sum + n)` sin el segundo argumento usa el primer elemento del array como valor inicial de `sum`, lo que produce un resultado distinto al esperado cuando el array está vacío o cuando el cálculo depende de empezar en `0`. Se detecta comparando el resultado con uno calculado a mano; la solución es siempre pasar el valor inicial explícito, como `0`.

**Confundir `filter` con `find`.** `filter` siempre devuelve un array, aunque tenga un solo elemento o ninguno; `find` devuelve el elemento directamente, o `undefined`. Usar `filter` cuando se necesita un solo objeto obliga a acceder con `[0]` después; usar `find` cuando en realidad se necesitan todos los elementos deja fuera al resto. Se detecta revisando si el resultado es un array (`[...]`) cuando se esperaba un objeto suelto, o viceversa.
