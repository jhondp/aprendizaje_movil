## Objetivo

Al terminar esta lección podrás animar un componente con `useSharedValue`, `useAnimatedStyle` y `withSpring`, y explicar por qué Reanimated corre en el hilo de UI.

**Prerrequisitos:** `07-nativo-ux-avanzada/02-notificaciones`

## Concepto

Una animación es una secuencia de fotogramas. Para que se vea fluida, el teléfono debe dibujar 60 fotogramas por segundo (o 120 en pantallas modernas): uno cada 16 milisegundos o menos. Si un fotograma llega tarde, el ojo nota un tirón.

En React Native hay dos hilos importantes. El **hilo de JavaScript** ejecuta tus componentes, tu estado y tu lógica. El **hilo de UI** dibuja la pantalla y recibe los toques. Si animas cambiando estado con `useState` en cada fotograma, cada paso cruza de JavaScript a la UI y vuelve a renderizar el componente. Cuando el hilo de JavaScript está ocupado (cargando datos, procesando una lista), los fotogramas se retrasan.

La analogía: imagina a un director de orquesta (el hilo de JavaScript) que tuviera que indicar cada nota a cada músico en tiempo real. Si se distrae un segundo, la música se corta. Reanimated le da la partitura a los músicos (el hilo de UI) antes de empezar: el director solo dice "toquen esta pieza" y los músicos la tocan solos, a tiempo, aunque el director esté ocupado.

Documentación oficial: https://docs.swmansion.com/react-native-reanimated/

### Reanimated 4 en Expo

Expo SDK 55 incluye Reanimated 4, que solo funciona con la New Architecture (la opción por defecto en Expo). Reanimated 4 depende del paquete `react-native-worklets`, que ejecuta funciones de JavaScript en el hilo de UI. La plantilla de Expo ya trae el plugin de Babel necesario; solo instalas los paquetes:

```bash
npx expo install react-native-reanimated react-native-worklets
```

### Valores compartidos

Un **valor compartido** (`useSharedValue`) es una caja que tanto el hilo de JavaScript como el de UI pueden leer y escribir. A diferencia del estado, cambiarlo no vuelve a renderizar el componente. Se lee y se escribe con `.value`:

```tsx
import { useSharedValue } from "react-native-reanimated";

const scale = useSharedValue(1);
scale.value = 1.5; // Jumps immediately, without re-rendering.
```

### Estilos animados

`useAnimatedStyle` recibe una función que devuelve un objeto de estilos calculado a partir de valores compartidos. Esa función corre en el hilo de UI cada vez que un valor cambia. El resultado se pasa a un componente animado, como `Animated.View`:

```tsx
import Animated, { useAnimatedStyle, useSharedValue } from "react-native-reanimated";

const offset = useSharedValue(0);

const animatedStyle = useAnimatedStyle(() => ({
  transform: [{ translateX: offset.value }],
}));

return <Animated.View style={[styles.box, animatedStyle]} />;
```

Fíjate en que el componente es `Animated.View`, importado de Reanimated. Un `View` normal no entiende estilos animados.

### Funciones de animación

Si asignas un número a `.value`, el cambio es instantáneo. Para que sea gradual, envuelve el destino en una función de animación:

- `withTiming(destino, { duration })`: recorre la distancia en un tiempo fijo con una curva de aceleración. Útil para aparecer y desaparecer.
- `withSpring(destino, config)`: simula un resorte. No tiene duración fija: depende de la masa, la rigidez y la amortiguación. Se siente natural para movimientos que responden al usuario.

```tsx
import { withSpring, withTiming } from "react-native-reanimated";

scale.value = withSpring(1.2);
opacity.value = withTiming(0, { duration: 300 });
```

Puedes ajustar el resorte: `withSpring(1, { damping: 8, stiffness: 120 })`. Menos amortiguación (`damping`) significa más rebote.

### ¿Hace falta la directiva `"worklet"`?

Un **worklet** es una función que corre en el hilo de UI. En versiones antiguas tenías que escribir `"worklet";` al inicio de cada una. Hoy, las funciones que pasas a `useAnimatedStyle`, `useDerivedValue` y a los gestos se convierten en worklets automáticamente. Solo necesitas la directiva si escribes una función auxiliar propia que llamas desde un worklet:

```tsx
function clamp(value: number, min: number, max: number) {
  "worklet";
  return Math.min(Math.max(value, min), max);
}

const animatedStyle = useAnimatedStyle(() => ({
  transform: [{ translateX: clamp(offset.value, -100, 100) }],
}));
```

Si desde el hilo de UI necesitas llamar a una función normal de JavaScript (por ejemplo, actualizar estado de React), usa `scheduleOnRN` de `react-native-worklets`. En código antiguo verás `runOnJS`, que cumplía la misma función.

### Estado de React o valor compartido

Usa estado de React para lo que cambia el contenido (textos, listas, qué pantalla se ve). Usa valores compartidos para lo que cambia fotograma a fotograma (posición, escala, opacidad). Si algo se anima, casi siempre es un valor compartido.

## Práctica

Toca el cuadrado. La escala usa `withSpring`, así que rebota; el desplazamiento usa `withTiming`. Cambia el `damping` del resorte y observa la diferencia.

<Snack
  platform="ios"
  sdkVersion="55.0.0"
  dependencies={{ 'react-native-reanimated': '4.2.1', 'react-native-worklets': '0.7.4' }}
  code={`import { Pressable, StyleSheet, Text, View } from "react-native";
import Animated, { useAnimatedStyle, useSharedValue, withSpring, withTiming } from "react-native-reanimated";

export default function App() {
  const scale = useSharedValue(1);
  const offset = useSharedValue(0);

  const animatedStyle = useAnimatedStyle(() => ({
    transform: [{ translateX: offset.value }, { scale: scale.value }]
  }));

  function handlePress() {
    const grown = scale.value > 1;
    scale.value = withSpring(grown ? 1 : 1.5, { damping: 6 });
    offset.value = withTiming(grown ? 0 : 60, { duration: 400 });
  }

  return (
    <View style={styles.container}>
      <Pressable onPress={handlePress}>
        <Animated.View style={[styles.box, animatedStyle]} />
      </Pressable>
      <Text style={styles.hint}>Toca el cuadrado</Text>
    </View>
  );
}

const styles = StyleSheet.create({
  container: { flex: 1, justifyContent: "center", alignItems: "center", gap: 32 },
  box: { width: 100, height: 100, borderRadius: 16, backgroundColor: "#10484a" },
  hint: { fontSize: 16 }
});`}
/>

## Errores comunes

**Usar un `View` normal con un estilo animado.** La animación no se mueve o aparece un error sobre valores no válidos. Ocurre porque solo los componentes de `Animated` de Reanimated entienden `useAnimatedStyle`. Se detecta porque el componente está importado de `react-native`. Solución: usa `Animated.View`, `Animated.Text` o `Animated.createAnimatedComponent`.

**Leer el valor compartido sin `.value`.** Se ve como `transform: [{ translateX: offset }]` dentro de `useAnimatedStyle` y la vista no se mueve o lanza un error. Ocurre por costumbre con variables normales. Se detecta revisando cada uso dentro del estilo animado. Solución: lee y escribe siempre con `offset.value`.

**Animar con `useState` en un bucle.** Se ve como un `setInterval` que llama a `setX` cada 16 ms. Ocurre porque es la forma que ya conoces de cambiar la UI. Se detecta porque la animación se entrecorta cuando la app hace otro trabajo. Solución: usa un valor compartido y una función de animación.
